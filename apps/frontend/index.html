            Antennentest

            Halte einen Tag nacheinander vor jede Antenne. Eine Antenne wird grün, sobald sie den Tag gelesen hat.

            Erstes Rennen anlegen

            Name und Rundenzahl genügen. Weitere Varianten (z. B. Zeitrennen) gibt es später über „+“ neben der Rennauswahl.

            Gestartet wird das Rennen erst später mit dem Knopf „Rennen starten“ – vorher werden keine Runden gezählt.
